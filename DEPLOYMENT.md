# Локальний frontend для Raspberry Pi 5

Результат — статичний React + TypeScript frontend. Налаштування Raspberry Pi,
Wi-Fi, QR-коду мережі, DNS, Nginx та Captive Portal до цієї роботи не входять.
Backend не створюється. Бізнес-логіка керування замками збережена.

## Збірка та файли для перенесення

На комп’ютері розробника:

```sh
npm ci
npm run build
```

Перенести **весь вміст `dist/`** у майбутній кореневий каталог сайту Nginx:

```text
dist/
  index.html
  boxyland-logo.png
  assets/
    index-<hash>.js
    index-<hash>.css
    web-<hash>.js
    inter-*.woff2
```

Назви з hash змінюються після збірки: переносити потрібно всю актуальну папку,
а не окремі файли. Копіювання `public/` окремо не потрібне: Vite вже додає його
вміст до `dist/`. `.env*`, `src/`, `node_modules/`, `android/` та `ios/`
на Raspberry переносити не потрібно. Node.js для обслуговування сайту не потрібен.

Встановлення npm-залежностей потребує доступу до реєстру на комп’ютері збірки;
готовому сайту інтернет не потрібен.

## Адреса і майбутнє API

Frontend відкривається через звичайний HTTP за локальною IP-адресою Raspberry.
Адреса Raspberry не зашита у web bundle. CSS/JS використовують локальні шляхи,
а API — поточний origin сайту:

- `GET /api/internal/states` — поточний стан.
- `POST /api/internal/{address}/open` — команда за явною дією користувача.

Користувач підтвердив адресу API `http://10.42.0.1:5000`, незмінний контракт
`address`, `active`, `locked`, `opened` та відсутність авторизації.
Остаточний URL сайту (IP і порт) ще не підтверджений. Наприклад, якщо сайт
згодом відкриватиметься на `http://10.42.0.1`, frontend надсилатиме запити на
`http://10.42.0.1/api/internal/states`, а майбутня серверна маршрутизація має
передавати їх до API на порту 5000. Frontend цього перенаправлення не створює.

Майбутній сервер повинен обслуговувати ці API-шляхи на тому самому origin.
Без локального API інтерфейс завантажиться, покаже відсутність зв’язку й
блокуватиме команди; фіктивні дані не підставляються. Статична папка сама
не реалізує API. Для перевірок відповіді підставляються тільки тестами.

Параметр `LOCKER_API_TARGET` використовується тільки dev/preview-проксі Vite.
`VITE_LOCKER_API_URL` збережений тільки для наявних нативних застосунків.
Колишня web-змінна Cloudflare більше не використовується.

## Офлайн і Captive Portal

- Шрифти Inter (латиниця й словацькі символи), стилі, скрипти, SVG-іконки та
  логотип завантажуються локально. CDN, Google Fonts, аналітики й зовнішніх API
  у вебверсії немає.
- Wi-Fi та локальний HTTP-сервер мають залишатися доступними. Сайт не потребує
  інтернету, але без зв’язку з Raspberry неможливо отримати новий стан замків.
- Cookies не використовуються. Заборонений `localStorage` не блокує роботу:
  мова залишається у пам’яті поточної сторінки, за замовчуванням — словацька.
- Немає залежності від service worker, HTTPS, встановлення PWA або зовнішніх
  переходів. Закриття вікна порталу завершує його сеанс та історію спостережень.
- Адаптивна сітка, нижня панель деталей, safe-area, плаваючі фільтри
  з плавним перемиканням й touch-зони враховують невеликі мобільні вікна.
- Цільовий мінімум: Safari/iOS 15.4+ та Chrome/Android System WebView 100+.
  Потрібні JavaScript, ES modules, Fetch, AbortController та HTML dialog.
  `AbortSignal.any/timeout` не потрібні; запити мають таймер 8 секунд.
- Якщо JavaScript повністю вимкнений, показується повідомлення з порадою
  відкрити ту саму локальну адресу в Safari/Chrome. Повноцінне керування
  React-застосунком без JavaScript неможливе.

## Перевірки

Перевірено 19 жовтня 2026 року:

- `format:check`, TypeScript/production build та перевірки API — успішно.
- Наявний `live-smoke.py`: контракти 56 портів, помилки/таймаути команд,
  підтвердження датчиками, відновлення та адаптивність — успішно.
- Production у Chromium: 320×740, 390×844, 844×390, 768×1024, 1440×1000.
- Production у WebKit: 390×844 і 844×390.
- Зовнішні запити заблоковані, cookies/storage заборонені, нові методи
  AbortSignal відсутні: завантаження, фільтри, деталі, підтвердження команд,
  втрата/відновлення API та перезавантаження — успішно.
- При повністю вимкненому JavaScript повідомлення видиме.
- `dist/`: 13 файлів  536 338 байт (приблизно 524 КіБ без стиснення).
  Прибрано 8 резервних WOFF-файлів; залишено локальні WOFF2-підмножини.

```sh
npm run format:check
npm run test:native
npm run build
python3 -m http.server 4174 --bind 127.0.0.1 --directory dist
# В іншому терміналі (Python Playwright, Chromium і WebKit):
python3 scripts/offline-smoke.py
```

`offline-smoke.py` перевіряє production-файли через HTTP-origin
`http://192.168.50.1`, перехоплений лише у тестовому браузері. Файли читаються
з локального статичного сервера. Зовнішні запити заборонені; сховище та cookies
недоступні, нові методи AbortSignal вимкнені. Дані контролера та POST-команди
перехоплюються, фізичні замки не відкриваються.

Емуляція WebKit/Chromium не замінює перевірку системних Captive Portal вікон.
Після налаштування мережі на Raspberry потрібна перевірка на реальних iPhone
та Android: вхід через QR, відкриття порталу, екранна клавіатура, зміна орієнтації,
закриття/повторний вхід, дозвіл залишатися в мережі без інтернету та локальне API.
Автоматичне відкриття порталу залежить від майбутніх мережевих налаштувань.
